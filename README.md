## IAM Security Audit Report

As part of this project, I conducted a security review covering Active Directory, Microsoft Entra ID and Auth0.

The assessment included password policies, Conditional Access, privileged access, group memberships, service accounts and federated authentication.

The report documents identified findings, remediation completed during the lab and recommendations for further improvement.
